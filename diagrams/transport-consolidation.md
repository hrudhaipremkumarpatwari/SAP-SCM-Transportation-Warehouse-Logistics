# Transport Consolidation Example

```mermaid
flowchart TD
    A[Weekly Vijayawada Demand] --> B{Fragmented Loads?}
    B -- Yes --> C[Vehicle Fill ~70.3%]
    C --> D[Higher Trips & Cost]
    B -- No --> E[Consolidate Compatible Orders]
    E --> F[Vehicle Fill ~93.75%]
    F --> G[One Trip Avoided / Week]
    G --> H[Illustrative Saving ~₹26,000 / Week]
```

The example demonstrates how transportation consolidation can improve asset utilization without changing customer demand. The values are illustrative and are used only for the internship simulation.
